## 📖 简介

**栖屿 · 书签工作台** 是一款专为高效信息整理者打造的现代化浏览器书签管理扩展与独立工作台。告别传统浏览器书签栏杂乱堆叠的痛点，栖屿提供**4列响应式栅格卡片**、**纯净视觉降噪设计**、**双向 Chrome 书签实时同步**以及**全键盘驱动的极速检索体验**。

---

## ✨ 核心特性

- 🎨 **极简现代视觉**
  - **规整网格**：4 列固定响应式 CSS Grid 排列，卡片高度标准化，告别拉伸变形。
  - **微质感轻阴影**：去除去繁琐描边，以悬停微浮雕投影（Elevation）打造轻盈质感。
  - **双主题与多材质**：暗黑 / 纯白双主题，支持多款弥散渐变、纯色与本地壁纸背景。
- 🔄 **双向 Chrome 书签同步**
  - 深度集成 Chrome Bookmarks API，增删改移实时双向写回。
  - 支持“本地书签”独立存储空间，敏感或临时书签不污染浏览器书签库。
- ⚡ **极速搜索与键盘工作流**
  - **拼音与缩写匹配**：支持中文拼音首字母检索，英文首字母缩写（如 `Windows Desktop` 搜 `WD`）。
  - **快捷键导航**：全站支持快捷呼出面板（`⌘K` / `Ctrl+K`）、搜索对焦（`/`）、卡片遍历切换（`j` / `k` / 方向键）。
- 🖼️ **自适应高清 Favicon 引擎**
  - 自动嗅探网站高清 Web App 图标与 SVG，低对比度背景保护与字符兜底，告别模糊失真。
- 🛠️ **专业管理与体检工具**
  - **重复书签查重**：智能识别同 URL / 同名重复书签，一键安全合并。
  - **死链与失效检测**：安全按需探测 HTTP 404 / 410 失效书签，保护私网目标不越权。
  - **备份与恢复**：支持 Chrome HTML 标准书签导入导出与完整 JSON 配置备份。

## 🚀 安装指南

### 1. 以 Chrome 扩展程序运行（推荐）

1. 下载或克隆本项目到本地：
   ```bash
   git clone https://github.com/thevipsong/qiyu-bookmarks.git
   ```
2. 打开 Chrome 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
3. 在右上角开启 **「开发者模式」** (Developer mode)。
4. 点击左上角 **「加载已解压的扩展程序」** (Load unpacked)，选择本项目目录。
5. 安装完成后，点击扩展栏的“栖屿”图标即可开启全新书签工作台！

> **提示**：更新代码后，只需在扩展管理页面点击扩展卡片右下角的刷新图标 🔄，再刷新书签页即可生效。

---

### 2. 本地独立网页模式（可选）

栖屿自带基于 Python 标准库实现的轻量级独立 Web 服务（无需额外安装任何第三方依赖）：

```bash
# 启动本地服务
python3 serve.py
```

在浏览器访问：`http://127.0.0.1:8765` 即可使用。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
| :--- | :--- |
| `⌘K` 或 `Ctrl+K` | 快速唤起命令控制台 / 全局搜索 |
| `/` | 聚焦到顶部搜索框 |
| `j` / `k` | 在书签列表中向下 / 向上移动选中项 |
| `↑` / `↓` / `←` / `→` | 网格卡片四向导航 |
| `Enter` | 打开当前选中的书签 |
| `Esc` | 退出搜索 / 取消多选 / 关闭弹窗 |

## 🔒 隐私与安全

- **完全本地运行**：书签数据只存储在您的浏览器本地和 Chrome 原生存储中，不设外部中转服务器，不上传任何个人隐私。
- **安全检查防御**：链接与图标检查严防 DNS 重绑定攻击，禁止向内网地址回传重定向，保护您的局域网资产安全。
