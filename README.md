# 栖点 · Chrome 书签工作台

按文件夹优雅展示 Chrome 书签，也可保存仅属于栖点的本地书签。界面支持明暗主题、毛玻璃拟态视效、网格/紧凑列表视图切换、多维度排序、折叠分组、名称与拼音首字母智能搜索、丰富右键操作、粘性分组标题和自定义壁纸背景。

## 安装与更新

1. 解压「栖点书签程序.zip」。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 `bookmark-gallery` 文件夹，并同意书签与网站图标权限。
4. 点击工具栏中的栖点图标，在新标签页打开书签工作台。已有旧版扩展时，在扩展管理页点击栖点卡片上的「重新加载」。

栖点读取当前 Chrome 用户配置中的书签。页面打开时，Chrome 的新增、修改、移动、删除会自动显示；关闭页面后，再次打开时重新读取。其他设备的书签先由 Chrome 自身的账号同步带到当前配置，栖点再读取。

## 核心功能与整理

- **灵活添加书签**：顶栏提供「+ 添加书签」按钮。在 Chrome 扩展模式下，可自由选择保存到 Chrome 指定文件夹或仅保存在栖点本地。
- **网格与列表双视图**：支持卡片网格视图与高密度紧凑列表视图，适应不同使用习惯与屏幕尺寸。
- **多种排序方式**：支持默认顺序、按名称拼音首字母/A-Z、按最近添加时间、按网站域名快速重排书签。
- **分组折叠与管理**：点击分组标题可折叠/展开当前分组，状态自动记住；操作菜单支持「折叠所有分组」；每个分组支持「重命名」，本地书签或 Chrome 文件夹名均可一键修改。
- **右键菜单与快捷操作**：
  - 支持右键点击书签或点击其 `⋯` 按钮：在新标签页/新窗口打开、复制网址、复制名称、收藏/取消收藏、编辑、移动分组或删除。
  - 编辑、移动或删除带 `Chrome` 来源的书签会立即写回 Chrome。
- **批量打开**：每个分组标题右侧可「打开本组全部」。超过 12 个链接时先提示确认。
- **重复书签清理**：查找完整网址相同的重复项，卡片化预览每组重复书签及其所属分组，支持单项针对性删除或一键自动合并（合并前自动导出 JSON 备份并继承星标收藏）。
- **失效链接检查**：
  - 扩展模式请求权限后并行检测；本地网页模式通过本机服务直连检测。
  - 检测进度实时展示；发现 404/410 或异常链接后，可在检查弹窗中直接「打开」、「编辑」或「删除」，无需再手动搜寻。

## 智能搜索与快捷键

- **多词智能搜索**：支持名称、网址、分类、分组以及中文拼音首字母（如输入 `bdwp` 匹配「百度网盘」），支持空格分隔的多关键词同时匹配，匹配字符实时黄色高亮提示。
- **快捷键系统**：
  - `/`：快速聚焦搜索框
  - `j` / `k` 或 `↓` / `↑`：在可见书签中上下移动选择项
  - `Enter`：在新标签页打开选中的书签
  - `e`：编辑当前书签
  - `f`：收藏 / 取消收藏当前书签
  - `m`：移动当前书签到其他分组
  - `Delete` / `Backspace`：删除当前选中的书签
  - `Esc`：关闭菜单、弹窗或清空搜索
  - `?`：随时呼出快捷键指南浮层

## 背景与视觉设置

右上角背景按钮提供 8 款高质感渐变与纯色（暮山、极光、晚霞、苍翠、碧海、石板、梅紫、曜黑），亦可上传自定义壁纸图片并微调毛玻璃模糊度与遮罩浓度。背景配置与暗黑模式刷新零闪烁即时呈现。

## 原有网页模式与数据迁移

在 macOS 上双击 `start.command`（或 `启动.command`），或运行 `python3 serve.py` 后打开 `http://localhost:8765/`，即可使用无需扩展的本地网页模式。本机服务自动抓取并解析网站高清图标（含现代 SVG 图标）缓存在 `.icon-cache`，并提供本地失效链接检查服务。

数据备份：点击「操作 → 导出书签」可导出 HTML 书签文件或 JSON 备份文件，数据完全私密掌控在本地。
