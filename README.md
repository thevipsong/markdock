# 栖点 · Chrome 书签工作台 (v2.0)

以极简文件夹树与纵向列表呈现 Chrome 书签，去除冗余图标干扰，带来安静、专注、快速的原生桌面级体验。支持 Chrome 书签双向实时同步、本地书签收纳、明暗主题、9 款氛围壁纸预设与自定义壁纸、智能拼音首字母搜索、重复书签合并清理与失效链接一键检查。

## Chrome 扩展安装与更新

1. 在 Chrome 地址栏输入 `chrome://extensions`，并开启右上角「开发者模式」。
2. **首次安装**：点击左上角「加载已解压的扩展程序」，选择本项目文件夹（`bookmark-gallery 2` 或 `bookmark-gallery`）。
3. **更新扩展**：若已在 Chrome 中加载过，直接在 `chrome://extensions` 页面中找到「**栖点 · 我的书签**」，点击卡片右下角的 **「重新加载」(🔄 旋转箭头图标)** 即可生效！
4. 点击 Chrome 浏览器工具栏拼图图标中的「栖点」，或将其固定在工具栏，点击即可秒开书签工作台（若已打开会自动聚焦定位，不重复堆积标签页）。

## 核心特性与亮点

- **极简文件夹列表（Folder Hierarchy）**：
  - 采用清晰的文件夹结构纵向排布，带有层级导轨线和平滑折叠/展开指示。
  - 彻底去除各站网络 Favicon 图标与厚重卡片，以极简圆点与清晰排版替代，零视觉杂音，瞬间加载上万条书签。
  - 支持一键「折叠所有文件夹 / 展开所有文件夹」，以及文件夹「重命名」与「打开全部」。

- **Chrome 书签实时双向同步**：
  - 打开工作台自动同步当前 Chrome 浏览器的书签树。
  - 在工作台中新增、编辑、删除、移动书签或重命名文件夹，即时写回 Chrome；Chrome 中书签的变化也会实时更新在页面上。
  - 支持同时管理 Chrome 共享书签与仅保存在本机的专属书签。

- **幻梦（Mirage）专属皮肤与材质系统（复刻自 dsh-dream-skin）**：
  - **8 套经典幻梦原生主题**：星云紫（默认旗舰）、沉静蓝、极光青、余烬橙、午夜黑（OLED 纯黑）、薄雾明亮（清透冷蓝）、iOS 扁平（苹果浅白）、Material 粉。
  - **多层专属径向弥散光（Ambient Diffuse Glow）**：每款皮肤拥有数学级精确调校的柔和光斑渐变与暗部分层，呈现极致高级感。
  - **双玻璃质感材质（Dual Materials）**：经典毛玻璃（奶霜质感，文字超清晰）与液态玻璃（通透润泽，折射光感高透底色）。
  - **品牌强调色叠加层**：内置 12 款精选灵感色块，支持原生取色器自定义、随机色彩与一键跟随皮肤。
  - **壁纸 2.0 体验**：支持主题弥散光、每日必应高清壁纸自动更新、本地图片上传（浏览器离线安全存储）与在线图片网址，配备模糊度与暗色遮罩滑块。
  - 启动阶段同步注入外观配置，刷新零闪烁、零白屏跳变。

- **多词智能搜索与拼音首字母**：
  - 按 `/` 快速聚焦搜索框。
  - 支持输入汉字、英文、网站域名，以及中文拼音首字母（如输入 `bdwp` 极速定位「百度网盘」）。
  - 匹配文本高亮呈现，毫秒级响应。

- **高效整理工具**：
  - **重复书签排查**：一键扫描重复网址，清晰罗列其所属文件夹，支持单项清理或智能合并（自动继承星标收藏）。
  - **失效链接检查**：批量探测死链（404/410/DNS解析异常），并在弹窗中直接编辑、跳转或删除。
  - **书签数据备份**：支持导出标准 Netscape 书签 HTML 文件或结构化 JSON 备份文件。

- **完整键盘导航**：
  - `/`：快速聚焦搜索框
  - `j` / `k` 或 `↓` / `↑`：上下浏览书签
  - `Enter`：在新标签页打开选中的书签
  - `e`：编辑当前书签
  - `f`：收藏 / 取消收藏
  - `m`：移动到其他文件夹
  - `Delete` / `Backspace`：删除当前书签
  - `?`：快捷键速查面板
