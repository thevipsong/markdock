# 栖点 · Chrome 书签工作台

按文件夹展示 Chrome 书签，也能保存仅属于栖点的本地书签。界面支持明暗主题、紧凑顶栏、网址与拼音首字母搜索、右键整理、粘性分组标题和自定义背景。

## 安装与更新

1. 解压「栖点书签程序.zip」。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 `bookmark-gallery` 文件夹，并同意书签与网站图标权限。
4. 点击工具栏中的栖点图标，在新标签页打开书签工作台。已有旧版扩展时，在扩展管理页点击栖点卡片上的「重新加载」。

栖点读取当前 Chrome 用户配置中的书签。页面打开时，Chrome 的新增、修改、移动、删除会自动显示；关闭页面后，再次打开时重新读取。其他设备的书签先由 Chrome 自身的账号同步带到当前配置，栖点再读取。

## 整理书签

- 右键点击书签，或点击其 `⋯` 按钮，可打开、编辑、移动分组或删除。
- 编辑、移动或删除带 `Chrome` 来源的书签会立即写回 Chrome。添加按钮目前创建的是栖点本地书签，不写回 Chrome。
- 移动时可选择已有文件夹，也可在选中的文件夹下新建子分组。
- 每个分组标题右侧可「打开本组全部」。超过 12 个链接时先提示确认。
- 操作菜单可查找完整网址相同的重复项，并在确认后导出 JSON 备份再合并。相同网站的不同路径或查询参数不会自动算作重复。
- 「检查失效链接」会在使用时请求访问网站的权限。检查先发送 HEAD；若服务器返回 404/410/405/501，再用 GET 复核。明确 404/410 列为疑似失效；登录限制、反爬、超时等列为待复查。检查不会删除书签。

搜索支持名称、网址、分类、分组以及中文标题的拼音首字母。例如输入 `bdwp` 可找「百度网盘」。拼音首字母是快速匹配，遇到多音字可能需要改用中文名称搜索。

快捷键：`/` 聚焦搜索；`j` / `k` 在可见书签间移动；`Enter` 打开当前书签。长标题悬停或聚焦时会显示完整标题和网址。

## 背景设置

右上角的背景按钮提供暮山、极光渐变，以及石板、梅紫纯色。也可上传自己的图片，调节模糊强度和遮罩浓度。图片会缩到最长边 2048 像素，保存在当前浏览器的本地数据库；其他背景设置保存在本地存储中。图片背景下顶栏和书签卡片会呈现毛玻璃效果。

## 原有网页模式与数据

在 macOS 上双击 `start.command`（或 `启动.command`），或运行 `python3 serve.py` 后打开 `http://localhost:8765/`，可继续使用无需扩展的本地网页模式。此模式不自动读取 Chrome 书签，也无法跨站检查失效链接。图标由本机服务读取网站声明的高清图标并缓存在 `.icon-cache`。

网页模式与扩展模式的本地数据分开保存。迁移以前的本地书签：在旧网页点击「导出 → JSON 备份」，再在扩展页面点击「导入」。如果旧数据只是 Chrome 书签的 HTML 副本，无需导入，扩展会直接读取。清除浏览器数据或移除扩展前，建议导出 JSON 备份。

Chrome 扩展模式优先使用 Chrome 的网站图标缓存；程序不向第三方图标聚合服务提交书签列表。
