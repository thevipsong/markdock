## 📖 简介

**MarkDock 书签坞** 是一款专为高效信息整理者打造的现代化浏览器书签管理扩展与独立工作台。告别传统浏览器书签栏杂乱堆叠的痛点，MarkDock 提供 **4 列响应式栅格卡片**、**现代极简 Dock 坞与毛玻璃飞出卡片**、**极致视觉降噪与呼吸感设计**、**Chromium 原生书签自动实时同步**以及**全键盘驱动的极速检索体验**。

## ✨ 核心特性

- 🚀 **极简现代 Dock 坞与智能飞出卡片 (v2.4.0)**
  - **折叠状态极简规整**：一键收起侧栏后自动隐藏树状缩进线与深层嵌套，转换为精致的 42px 居中圆角卡位 Dock 坞，提供活动项微光指示点（Accent Dot）。
  - **智能毛玻璃飞出卡片（Dock Flyout）**：鼠标悬停任一 Dock 节点即刻平滑滑出毛玻璃信息卡，展示文件夹全名、书签总数与深层子目录列表，支持一键穿透直达。
  - **平滑避让排版**：侧边栏文件夹悬停时数字徽标平滑左移让位，彻底消除三点按钮（`···`）与书签数量碰撞，保持规整呼吸感。
- 🎨 **通透悬浮布局与精致视觉降噪**
  - **通透悬浮顶栏**：打通顶部 Header 外框，Logo 与搜索胶囊自然悬浮于画布背景，空间感彻底展开。
  - **100% 完整域名呈现**：卡片子目录标签移至标题行右上角，第二行独占 100% 宽度，局域网 IP、端口与长域名不再被过度截断。
  - **消除图标容器双层套娃**：浅色模式纯白底板配极淡内描边，深色模式采用深灰半透明底色，图标视觉纯净且不刺眼。
  - **侧边栏细节打磨**：弱化选中项生硬描边，改用柔和半透明高亮与左侧指示条；智能识别文件夹前缀 Emoji 并替代默认 SVG；空文件夹零计数自动隐藏，数字徽标纯净平铺。
  - **品牌大小写自动规范**：智能校正常用科技与社交品牌英文大小写（如 Twitter、GitHub、ChatGPT、Jellyfin 等），卡片排版井然有序。
  - **沉浸背景与高级质感系统**：暗黑 / 纯白双主题独立记忆；内置 6 套高级空间渐变、12 款质感纯色快捷卡、精选矢量艺术壁纸库、微软 Bing 每日 4K 高清壁纸自动同步；支持微质感点阵网格与卡片毛玻璃通透浮雕质感。
- 🔄 **Chromium 书签自动双向同步**
  - 深度集成浏览器原生 Bookmarks API，增删改移实时自动写回 Chrome / Edge。
  - 统一数据源，告别多来源切换困扰，打开即是最新收藏夹。
- ⚡ **极速搜索与键盘工作流**
  - **拼音与缩写匹配**：支持中文拼音首字母检索，英文首字母缩写（如 `Windows Desktop` 搜 `WD`）。
  - **快捷键导航**：全站支持快捷呼出面板（`⌘K` / `Ctrl+K`）、搜索对焦（`/`）、卡片遍历切换（`j` / `k` / 方向键）。
- 🖼️ **自适应高清 Favicon 引擎**
  - 自动嗅探网站高清 Web App 图标与 SVG，低对比度背景保护与字符兜底，告别模糊失真。
- 🛠️ **专业管理与体检工具**
  - **重复书签查重**：智能识别同 URL / 同名重复书签，一键安全合并。
  - **死链与失效检测**：安全按需探测 HTTP 404 / 410 失效书签，保护私网目标不越权。
  - **备份与恢复**：支持标准 HTML 书签导入导出与完整 JSON 配置备份。

## 🚀 安装指南

### 1. 以 Chrome / Edge 扩展程序运行（推荐）

本项目基于标准 Chromium Manifest V3 规范构建，100% 原生支持 **Google Chrome**、**Microsoft Edge**、**Brave**、**Arc** 等基于 Chromium 的现代浏览器：

#### Chrome 浏览器：
1. 打开 Chrome，在地址栏输入：`chrome://extensions/`
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」**。
4. 选择本项目所在文件夹。

#### Edge 浏览器：
1. 打开 Edge，在地址栏输入：`edge://extensions/`
2. 在左侧边栏底部开启 **「开发人员模式」** 开关。
3. 点击主界面顶部出现的 **「加载解压缩的扩展」** 按钮。
4. 选择本项目所在文件夹。

> 💡 **提示**：安装后点击浏览器右上角扩展栏拼图图标，把“MarkDock”固定到工具栏即可一键打开；后续更新代码后，只需在扩展管理页点击刷新图标 🔄 即可。

---

### 2. 本地独立网页模式（可选）

MarkDock 自带基于 Python 标准库实现的轻量级独立 Web 服务（无需额外安装任何第三方依赖）：

```bash
# 启动本地服务
python3 serve.py
```

在浏览器访问：`http://127.0.0.1:8765` 即可使用。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
| :--- | :--- |
| `⌘K` 或 `Ctrl+K` | 快速唤起命令控制台 / 全局搜索 |
